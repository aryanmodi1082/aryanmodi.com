# aryanmodi.com — first version

A responsive personal website starter for Aryan Modi.

## Publish
1. Upload these files to a GitHub repository.
2. Import the repository into Vercel.
3. Connect `aryanmodi.com` in Vercel's domain settings.
4. Before launch, replace placeholder social/email links and add your real photos.
5. Keep the marriage profile private/password-protected before publishing.
